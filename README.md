# ODA Technologies 견적서 시스템

## 기능
- 견적서 작성 (문서번호 자동생성, DC율 계산, Excel/PDF 출력)
- 담당자 관리
- 거래처/담당자 관리
- 품목·규격·사양 관리

## 로컬 개발
```bash
npm install
npm run dev
```

## GitHub Pages 배포
1. 이 저장소를 GitHub에 push
2. Settings → Pages → Source: **GitHub Actions**
3. 이후 main 브랜치 push 시 자동 배포
